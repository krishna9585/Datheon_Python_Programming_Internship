# Hangman Word Guessing Game

## Project Overview
A terminal-based word guessing game developed using Python
as part of my Datheon Python Programming Internship.

## Features
- Random English word selection
- Hidden letters and correct-letter display
- Six incorrect guesses allowed
- ASCII hangman drawings
- Duplicate-guess protection
- Input validation
- Win and defeat messages
- Replay option

## Requirements
- Python 3
- No external libraries required

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   python hangman.py

## Run Automated Tests
Run:

   python -m unittest -v

## Files
- hangman.py: Main game
- test_hangman.py: Automated tests
- README.md: Project documentation
- requirements.txt: Dependency information
